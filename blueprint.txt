MINESIGHT — CONDENSED BLUEPRINT
Coal Mine Governance & Compliance Platform (SIH 2026)

PROBLEM: Compliance/safety/contractor data is fragmented across paper
and spreadsheets — delayed detection, no audit trail. One connected
system. No real IoT, no AI-generated risk scores — every flag traces to
a real data point.

ROLES (2 only):

CONTRACTOR (own data only):
License/Cert Wallet (auto expiry tracking) · Attendance Register ·
Worker Roster (training + PPE per worker) · Machinery Register (service
dates) · Explosives Stock (blasting task_type only) · Unresolved Action
Center (red-flagged, upload proof to clear) · Risk Indicator (Low/Mod/
High, deterministic, affects contract eligibility).

SUPERVISOR (writes observations only, not contractor profiles):
Contractor Directory (searchable, Risk Level, Violation Frequency Meter,
Restricted/Blacklisted flag) · Observation Logger (category, severity,
photo, GPS/timestamp) · Daily Yield & Environment Tracker (tonnage,
dust, effluent, noise vs threshold) · Platform-Wide Warning on breach ·
Closure Verification (proof -> clear -> audit trail) · Contractor
Drill-Down (license + machinery status only) · OCR Upload (extracts
report values, updates env widgets + risk %).

task_type: blasting | transport | excavation | maintenance — set once at
onboarding, drives rendering, never a login prompt.

RULES: deterministic flags only, no black-box AI; LLM limited to
document extraction; no cross-contractor data exposure; missing data =
"Pending," never invented.

DIFFERENTIATOR: closes the loop — issue -> flag -> proof -> verified ->
audit trail.
